# Roadmap de desenvolvimento

## Fase 1 — concluída nesta entrega
- Home responsiva baseada no Figma
- fundo com grid, glows e frames animados
- animações de entrada no scroll
- placeholders para fotos e vídeos
- áreas de voluntariado
- espaço visual para formulário
- identidade preto / branco / laranja
- logo incluída em `public/brand`

## Fase 2
- substituir placeholders pelas fotos reais
- menu mobile
- página/overlay de cada evento
- modal ou página de cada área de voluntariado
- formulário real

## Fase 3
- Supabase para voluntários
- painel de inscrições
- confirmação via WhatsApp/e-mail
- conteúdo administrável

## Fase 4
- GSAP ScrollTrigger para storytelling cinematográfico
- vídeos de eventos
- otimizações de performance
- SEO/Open Graph
- deploy em Vercel
